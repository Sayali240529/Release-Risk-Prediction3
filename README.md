# Release-Risk Prediction Engine
> Multimodal AI system that predicts deployment risk from Git commits, CI logs, and bug report text — before a release reaches production.

---

## Quick Start

```bash
# 1. Install Python dependencies
pip install -r requirements.txt

# 2. Generate dataset (Member 1)
python -m extractor.dataset_builder simulate --rows 500 --out data/features.csv

# 3. Train model & generate SHAP artifacts (Member 2)
python -m model.train
python -m model.explain
python -m model.ablation

# 4. Launch the Enterprise React Cockpit & FastAPI Server (Member 3)
python -m uvicorn backend.main:app --port 8080
# Now open: http://127.0.0.1:8080 (or http://localhost:3000 for Vite live dev)

# 5. Run CI gate test (Member 3)
python ci_gate/check_release.py --input ci_gate/sample_input.json
```

## Member Contributions

### Member 1 — Data Pipeline & Feature Engineering
- `extractor/git_features.py`: Extracts commit churn, file entropy, author frequency using PyDriller
- `extractor/ci_features.py`: Parses CI log files for warning/error counts, test duration, flakiness
- `extractor/text_features.py`: Risk keyword extraction from PR titles and bug descriptions
- `extractor/dataset_builder.py`: Merges all three modalities into `data/features.csv`

### Member 2 — ML Model, Evaluation & Explainability
- `model/train.py`: Trains CatBoost classifier with class-imbalance handling
- `model/evaluate.py`: PR-AUC, ROC-AUC, confusion matrix evaluation
- `model/explain.py`: SHAP TreeExplainer — global and per-release factor attribution
- `model/policy.py`: Maps risk score to AUTO_PROMOTE / HOLD_CANARY / MANUAL_REVIEW
- `model/predict_api.py`: Clean `predict()` interface used by all downstream consumers

### Member 3 — Dashboard & CI Integration Gate
- `dashboard/app.py`: Streamlit interactive dashboard with risk gauge, SHAP charts, history log
- `ci_gate/check_release.py`: CLI gate script (exits 0=safe, 1=blocked for CI pipelines)
- `ci_gate/sample_github_action.yml`: Sample GitHub Actions workflow integrating the gate

## Novelty vs. Prior Work

Extends **König et al. (2025)** — *Boost-Classifier-Driven Fault Prediction* (CatBoost on Git metrics only) — by adding:
1. CI log signal modality
2. PR/bug report text modality
3. Local SHAP explainability per release
4. Automated policy engine (`PROMOTE` / `HOLD` / `ROLLBACK`)
5. Interactive web dashboard + CI gate integration
